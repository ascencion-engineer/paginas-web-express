# ⚡ Páginas Web Express

Landing page profesional para un servicio de desarrollo de sitios web dirigido a negocios locales, emprendedores y pequeñas empresas.

El proyecto fue desarrollado con HTML, CSS y JavaScript, incorporando animaciones, diseño responsive, integración con WhatsApp y una experiencia visual orientada a la conversión.

## 🎯 Sobre el proyecto

**Páginas Web Express** es una landing page diseñada para promocionar servicios de desarrollo web.

El objetivo principal del proyecto es presentar los servicios de forma clara y profesional, generar confianza y facilitar que un posible cliente solicite una cotización.

La página utiliza una estructura orientada a conversión:

- Presentación del servicio
- Llamada a la acción principal
- Beneficios
- Servicios disponibles
- Proceso de trabajo
- Llamada a la acción final
- Contacto directo por WhatsApp

## ✨ Características

- 📱 Diseño completamente responsive
- 🎨 Diseño moderno con sistema de colores y tipografías personalizado
- ⚡ Animaciones de entrada utilizando GSAP
- ✨ Fondo animado con partículas
- 📈 Animación de progreso de construcción del sitio
- 📱 Menú responsive para dispositivos móviles
- 💬 Integración directa con WhatsApp
- 🔎 Estructura HTML semántica
- ♿ Soporte para `prefers-reduced-motion`
- 🎯 Llamadas a la acción orientadas a conversión
- 🌐 Compatible con GitHub Pages
- 🧩 Arquitectura sencilla y fácil de mantener

## 🛠️ Tecnologías utilizadas

### Frontend

- HTML5
- CSS3
- JavaScript (ES6+)

### Librerías

- [GSAP](https://gsap.com/) — Animaciones
- [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) — Animaciones controladas por scroll
- [Particles.js](https://vincentgarreau.com/particles.js/) — Fondo de partículas
- [Font Awesome](https://fontawesome.com/) — Iconografía

### Tipografías

- Bricolage Grotesque
- Instrument Sans
